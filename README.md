# 📊 Sales Analytics End-to-End Project
Complete end-to-end sales analysis project covering data processing, database querying, and dashboard visualization.
## 🛠️ Tools Used

**Excel:** Data cleaning and summary formulas.
* **SQL:** Database querying, grouping, and filtering (`GROUP BY`, `HAVING`).
* **Power BI:** Interactive dashboard with KPI cards (`87` quantity, `190K` sales), charts, and custom formatting.
